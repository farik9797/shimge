# Antigravity Project Instructions & UI/UX Design System Rules

This project follows the **UI/UX Design Pro & Modern Frontend Architecture** standards.

## Active Installed Skills & Guides:
1. **`ui-ux-design-pro`**: Visual archetypes (Industrial B2B, Liquid Glass, Bento Grid, Aurora), color palettes, font pairings.
2. **`frontend-design`**: Contextual component architecture, React 19, TypeScript, responsive layout best practices.
3. **`ai-ui-ux-skill`**: Design tokens, spacing scale, accessibility (WCAG 2.1 AA), typography hierarchy.
4. **`tailwind-patterns`**: Production patterns for metric cards, faceted catalog filters, modal drawers, and responsive tables.
5. **`antigravity-design-expert`**: Weightless floating 3D interfaces, depth tokens, liquid glass, refractive shaders, elevation strata.
6. **`gsap-best-practices`**: Smooth 60/120fps motion architecture, ScrollTrigger automation, scrubbing, pinned section transitions.
7. **`interactive-cursor`**: Custom inertial cursors, magnetic button physics, mix-blend-mode transformations, touch bypass.
8. **`spatial-ui-visionos`**: Spatial UI & visionOS design guidelines, thick blurred glass, floating ornaments, gaze/hover highlights.
9. **`data-brutalism`**: Raw telemetry, sharp 1px gridlines, monospaced dense data matrices, industrial signal flags.

## Project Guidelines:
- **Design Philosophy**: High-precision industrial B2B aesthetic, clear visual hierarchy, authoritative typography, weightless interaction physics, high conversion rates.
- **Tech Stack**: React 19 + TypeScript + Vite + Tailwind CSS + Lucide Icons + Motion / GSAP.
- **Code Quality**: Strict typing, atomic component separation, smooth micro-interactions, responsive design across mobile/tablet/desktop.
